# 小小理財家｜Godot 網頁版

這個儲存庫包含 Godot 專案原始碼，以及可直接透過瀏覽器遊玩的網頁匯出檔。

## 開啟專案

使用 Godot 4.7.2 開啟此資料夾中的 `project.godot`。網頁匯出預設為 `Web`，輸出到儲存庫根目錄。

## GitHub Pages

在 GitHub 儲存庫的 **Settings → Pages**，將來源設為 `Deploy from a branch`、分支設為 `main`、資料夾設為 `/(root)`。發布後網址為：

https://sabrina05241102-dev.github.io/game1/

## 字型授權

本遊戲使用 Noto Sans TC，依 SIL Open Font License 1.1 發布；授權全文見 `fonts/OFL.txt`。

字型來源：Google Fonts 的 Noto Sans TC。字型版權及保留名稱資訊依上游字型資訊（Adobe，Reserved Font Name: Source）。
