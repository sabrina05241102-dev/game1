# 小小理財家｜校園理財冒險

這個儲存庫提供即開即玩的單頁遊戲，以及 Godot 4.7.2 網頁匯出版。首頁是輕量版，適合直接分享與手機遊玩；Godot 版位於 `godot-web/`，首次開啟需要下載較大的執行檔。

## GitHub Pages

在儲存庫 **Settings → Pages** 選擇 `Deploy from a branch`、`main`、`/(root)`。發布後首頁網址：

https://sabrina05241102-dev.github.io/game1/

Godot 網頁版：

https://sabrina05241102-dev.github.io/game1/godot-web/

## Godot 專案

使用 Godot 4.7.2 開啟此資料夾中的 `project.godot`。匯出範本使用 Web preset。

## 字型授權

Godot 版使用 Noto Sans TC，依 SIL Open Font License 1.1 發布；授權全文見 `fonts/OFL.txt`。
